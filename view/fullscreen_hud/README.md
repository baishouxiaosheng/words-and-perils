# 全屏冒险 HUD · 幻想器物形态精修

此目录是原创代码绘制的界面素材。使用完整 Noto CJK 字体；不含商业游戏 UI 美术。

## 位置与交互

- 世界始终占满窗口，没有常驻侧栏
- 地区与回合在左上；旅人肖像、生命、体力在左下
- 右上小地图及图标：聚焦旅人、全图、行囊；文字说明通过悬停显示
- 右上菜单分为冒险、主持手记、连接与高级、显示
- 底部居中对白与自由输入；对话记录向上打开，底板55%不透明，滚动/点击不会穿透到场景
- 查看全图时暂时收起对白和历史；草稿与历史开关保留。底部聊天图标可在保留当前镜头时恢复对白
- F11切换全屏；Esc优先收起历史/扩展输入，否则退出全屏。普通启动最大化

## 回合与离线状态

“结束回合”提交意图；当前没有实时AI连接，因此等待有效人工裁定时不会提交世界状态。导入有效评估后，默认流程通过原有引擎依次锁定结果、暂存、提交一次。失败保持最后安全阶段；锁定的结果不能重掷。

手动 JSON、署名样例、独立保存读取与逐阶段调试保留在高级窗口。任何自由文字都不能自动套用署名样例。

## 造型

以淡稻黄为基底。参考成熟幻想游戏HUD的组合形态，使用独立圆形肖像框、相连的细长资源饰带、连续行动基座、右端圆形回合章及小地图径向配件。轮廓和纹样为原创；表面仅用两个主要明暗组，不复制商业游戏资产。正文深色，场景名称仍白色粗体软影。记录底板为55%不透明，文字行另有局部阅读衬底。没有写实金属、摄影纹理或脏纸。

## 多屏适配与名称避让 · 2026-10-03

`responsive_layout.gd`负责原生像素HUD重排，世界SubViewport保持与窗口客户区1:1。1080p以下不缩小基础正文；1440p按高度放大字体与布局，超宽屏增加世界可见宽度。`world_label_layout.gd`按真实字形边界协调角色、聚落、地标及当前选中物件的名称，避开其他名称与HUD；没有空间时只隐藏低优先级名称，绝不更改模型、位置事实或选择引用。

验收入口为`tests/screen_adaptation/run_native_matrix.sh`，须从有原生显示连接的终端运行。1280×720、1920×1080、2560×1440、3440×1440、1920×1200各128项检查通过；另有49项F11、同进程缩放恢复与选中物件名称检查。共39张未重采样截图。证据、精确尺寸、哈希与尚未验证的内容见`artifacts/screen_adaptation_20261003/ACCEPTANCE.md`和`acceptance_summary.json`。

旧`tests/test_responsive_layout.gd`仍针对已退役侧栏，不应作为当前全屏HUD的验收依据。物理DPI、目标显卡性能、更多工具窗口与长文本组合仍在后续日程中。名称避让已覆盖当前默认世界与选中物件；更密集角色和更多镜头仍需压力测试。

### 后续文字与按钮修订 ·12:06 UTC

当前完成的是原生1280×820控件样式表的人工视觉检查与44项辅助检查，见`artifacts/ui_readability_20261003/controls_1280x820.png`及`component_review.json`。这是不加载3D世界的真实原生控件预览。最新样式在完整游戏内的720p/1440p布局、长文本与展开输入仍待内存余量允许后验证，不得以旧矩阵宣称已全部通过。
