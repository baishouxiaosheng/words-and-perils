# 村庄冒险：一次近战遭遇

本次是新的独立村庄冒险版本。新建入口仍叫“村庄冒险”；原村庄进度可从“连接与高级 → 旧进度与测试 → 继续原村庄冒险”打开。所有旧地图、物品、NPC、植被版本与存档命名保持原样，不能自动升级。

## 玩法

- 一个固定不巡逻的持刃拦路者，守住一个完整地格
- 旅人开始携带并装备现有潮岸木杖：攻击消耗1点体力，命中伤害3、擦伤1
- 拦路者的苦叶短刃：攻击消耗1点体力，命中伤害2、擦伤1，完整命中可施加不叠加的中毒
- 近战必须相邻，且两格之间存在真实干地通路；建筑与水面阻断的边不可攻击
- 双方每个有意行动都需要自己的有效评估；等待、取消、选中、请求与叙述不造成伤害
- 每次旅人提交行动后，仅当敌人仍活着、体力足够、双方仍在合法近战范围内，才安排敌方独立待评估回合
- 新施加的中毒从后续已提交行动开始结算，每次1点、两次后结束；敌方提交的行动也计入
- 生命为零时不能发起行动。倒下的敌人仍占据原格，不能穿过
- 不含额外敌人、自动攻击、巡逻、战利品、武器交换、经济、远程或法术

“连接与高级”有明确标出的离线近战示例。默认没有真实供应商配置，本次测试只使用预设裁定与本地模拟传输，未调用实时服务或产生供应商费用；现有模型设置不变。

## 物理与呈现范围

敌人使用原始完整尺寸棋子。位置从原始网格中确定，完整原生网格占地必须有干地支撑，同时保留原起点与除敌人所在格之外的原连通分量。若不能满足，明确拒绝该地图的遭遇准入，不替换种子、不缩小角色、不改地形。

新遭遇的接近路径与邻格绕行使用实际加权路线，单独证明旅人0.38占地与实际行礼包的有限运动样本。这个证明不扩展为全地图任意连续碰撞保证。半径4/12、海岸与高原配方的种子726381已通过专项几何检查；其他种子需要同样准入。

伤害与中毒演出只来自新提交且哈希匹配的回执。读取、重选或恢复不重播伤害。倒下姿态只沿竖直方向压低，不扩大已证明的平面占地。

## 公开资料与容量

新版本明示使用半径3的局部资料窗口，最多37格，再加入精确选中目标与已知敌人的支持地格，最多39格。双方角色、武器、回合归属、敌人占格和完整近战邻接列表保留。窗口外地形仍由完整本地规则校验，省略不代表可通行。

请求硬上限仍为65,536字节。连接层的96或128KiB设置不会扩大本版本。超限必须明确拒绝，不能裁剪目标、事实或偷偷提高上限。

每个可能安排敌方行动的后果分支，会在随机检定前验证完整下一次敌方请求，并保守预留5,120字节给未来有界回合记忆及其封装。不能容纳的分支使评估准备失败，不会提交到无法发送评估的敌方回合。

## 保存与验证

独立保存已冻结意图、已锁定随机结果、已提交回执、NPC信息、真实地形与敌人安放证据。原始棋子占地以明确的float32小端字节编码保存，支撑包络使用原有量化坐标；严格校验不依赖浮点容差。新版本首先通过真正的JSON编码/解析与文件写入/读取，再验证各个行动阶段。历史逐回合重建登记行动后果与中毒钩子。已锁定的待处理动作沿用原引擎完整随机重建验证；已提交历史的骰子检查保留组件、数值范围和回执哈希一致性，不宣称加密防篡改。

本文件描述实现边界。最终通过项、失败项和未运行项以本次独立验收报告为准；源项目不是独立可执行发行版。
