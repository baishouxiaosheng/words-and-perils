# 村落行囊探索

右上菜单 → 冒险 → 新地形探索，勾选“加入沿途村落（含行囊，独立进度）”。新旅程包含一位旅人、一件行礼包、一座小村落、三幢房屋和连接邻格的入口道路。下次从“继续村落行囊探索”恢复。

- 点击旅人、地格、行礼包、村落、房屋或道路，查看选中的目标。点击本身不执行行动
- 在“连接与高级”中选择移动、观察、休息、放下行礼包或拾回行礼包的行动示例，再结束回合并应用预设裁定。自由文字等待导入评估，也可以在锁定结果前取消
- 房屋会挡住实际占据的通路。绕到保留的入口，再沿路进入村落广场；道路不会降低原地形的体力费用
- 在村落里放下的行礼包保留原来的地图位置，可以走开后再从同格或直接连通的邻格拾回。建筑挡住的边不能隔墙伸手拾取
- 保存可保留待评估的目标、已锁定结果、走过的路线和物品归属。之后选中别的对象不会改写已提交的目标

此版本尚未接入实时AI。村落提供可选择的固定建筑与实际通路阻挡，没有人物、对话、交易、进屋、城门、拆建、战斗或实体河流。源地图中的河流标记不代表已建立河面或渡河规则。

每种探索分别保存。开启村落不会给普通新地形或行囊旧进度添加房屋和人物。安放校验不通过时会报错并保留当前旅程，不换种子、不改地形。
