# 可选的新地形行囊探索

在“新地形探索（v3，可选）”勾选“带行礼包探索”，再生成地图。继续进度使用“继续新地形行囊探索”。此模式有独立进度；普通新地形、旧多地貌和海岸旅程保持各自状态。

旅人自带一件行礼包。点击模型或从行囊选择“查看”只选择目标，不自动行动。可以整件放下，或从同格与直接连通的相邻干地拾回。点击目标后提交行动，评估结果由固定规则检查、结算；没有实时AI连接。行动示例使用预设评估，任意自由文本需要导入评估或取消。

支持移动、观察、休息、放下和拾回，保存待评估、已锁定、已结算等阶段并恢复。目标的物品身份、归属和所在位置随提交冻结；之后换目标不会改写旧行动。已有历史在载入时逐回合验证。

只支持整件行礼包；没有拆分、消耗、装备、转交、交易、NPC、战斗、城镇或实体河流。此模式不自动给旧存档增加物品。河流是来源地图资料，尚未提供实体河道、渡河或桥梁规则。

模型被同格棋子遮挡时可从行囊查看；放下后正常走开可看见原地物品。地面模型使用真实地形全足迹干燥支撑检查；它不改变地图、导航、行动成本或随机数。
